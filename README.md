# World TEBMA Hub

Create a modern, dynamic website for an international organization named World TEBMA Martial Arts Federation.

The website must be fully in English, with a professional, standard design that includes rich UI components and a visually appealing layout.

Required Sections:

- News

- Membership

- Gallery

- Rules

- Styles

- Certificate Verification (Check Certificates)

- About

- Contact

- Photo Dictionary

CMS Dashboard Requirements:

- User-friendly and easy to manage

- Use dedicated pages for forms (avoid modal-based forms)

- Clean and intuitive navigation for administrators

Technical Requirements:

- High SEO optimization (meta tags, structured content, performance-focused)

- No Server-Side Rendering (SSR)

- Must be suitable for deployment on shared cPanel hosting (simple deployment setup)

Ensure the platform is scalable, fast, and optimized for both users and administrators.
